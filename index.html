Cómo funciona la plataforma

Ruta progresiva — completá un módulo para desbloquear el siguiente

La plataforma se recorre en orden: empezás por el Módulo 0 (Quiénes somos Grupo GRITT), lo leés entero, completás su evaluación y eso desbloquea el Módulo 1. Y así hasta el examen final del Módulo 10. Cada módulo tiene tres piezas dentro de esta misma página: el objetivo de aprendizaje, el contenido completo con frases listas para usar con cliente, los casos prácticos, y la evaluación embebida que valida que el contenido se incorporó.

Una vez que completás los 12 módulos al menos una vez, podés volver a abrir cualquier módulo en cualquier orden — la plataforma queda como manual de campo permanente. Para desbloquear el siguiente módulo necesitás el 100% de aciertos en la evaluación. Certificación interna al aprobar el examen final del M10 + el caso de inversión del M11.
