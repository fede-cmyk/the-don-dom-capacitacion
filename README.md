# The Don Dom La Isla — Plataforma de Capacitación

Plataforma de capacitación comercial Grupo GRITT para vendedores profesionales de real estate.

- **Sitio:** https://the-don-dom-capacitacion-la-isla.netlify.app
- **Auth:** Netlify Identity + Google OAuth
- **Módulos:** 11 (M0 a M10) — docx + PDF + Jotform por módulo
- **Tests:** umbral 100% para avanzar

## Estructura

- `index.html` — Plataforma principal (single-page, vanilla JS)
- `netlify.toml` — Config Netlify (headers + cache)
- `pdfs/` — PDFs descargables por módulo

## Deploy

Auto-deploy desde main vía Netlify.
